# WorkPal v1.2.0：代理守护与申请功能移除

## 使用

退出旧版后，运行 `dist/proxy-guard-20260920/WorkPal/WorkPal.exe`。

托盘“代理守护”菜单包含：

- 开启定时守护：手动启用，默认每 60 秒检查，可选 2 或 5 分钟。
- 立即检查并修复一次：无需开启定时检查；守护已开启时唤醒同一个线程。
- 在家连接公司：临时关闭代理后打开 FortiClient，登录由用户完成；确认连接后启用固定代理。
- 暂停守护：保留当前代理；退出 WorkPal 同样不会恢复旧 PAC。
- 恢复接管前的代理：显式还原最初备份。

识别公司有线或已连接的 FortiClient，并验证公司代理 TCP 可达；未知状态不触发断线处理。未发生变化时不重复写入。外部代理变更在下次检查修复，检查之间仍可能短暂影响访问。

已移除在宅申请、提醒、页面校准、凭据/日期/设置窗口，以及专用浏览器打包依赖。旧版历史数据和旧安装包保留，新版不加载申请设置。
