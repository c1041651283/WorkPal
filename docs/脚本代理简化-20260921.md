# 脚本代理简化（v1.2.4）

- 启动 WorkPal：脚本代理开、手动代理关，守护不自动开启。
- 新按钮“开启脚本代理（关闭手动代理）”：先暂停守护，再切回上述状态。
- “开启定时守护”和“立即检查并修复一次”可照常手动使用，不需要任何检疫确认。
- 已删除“开始公司检疫”“检疫已通过”及对应的等待、批准、网络变化后重新确认等逻辑。切到有线后也不再自动开启守护。
- 原来的在家 FortiClient 连接助手、解锁/唤醒复查、1/2/5 分钟间隔及恢复原代理功能保留。

在公司完成检疫、看到绿色 OK 后，自行开启守护即可。在家使用原来的“在家连接 / 重新连接公司”。脚本按钮不运行或重启检疫程序；已有网络切换中配置的 iNetSec 若在运行则保留，未运行时沿用配置路径启动。

原代理备份继续保留。启动或按钮切换失败会通知；不会声称已经成功。测试不修改真实系统代理或 VPN 配置。

验证：175 项测试通过。覆盖启动默认脚本代理、手动开启守护、脚本按钮暂停守护、备份保留及写入失败、并发点击、切换有线不自动开启守护。
