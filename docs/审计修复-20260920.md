# WorkPal v1.2.2 审计修复

本次在已有未提交修改上实施修复，没有提交 Git，没有删除用户配置或旧安装包。

## 修复内容

| 项目 | 修复后的行为 |
| --- | --- |
| 网络切换 | 保存网卡状态和实际 WiFi 配置；先断后连，目标连接确认后才报告成功；失败时恢复原状态，并报告恢复失败的具体步骤。 |
| WiFi 配置 | 使用按 SSID 派生的 WorkPal 专用配置名；修改前备份已有专用配置，失败时恢复或移除新配置，不覆盖私人同名配置。备份不导出明文密钥，临时文件自动清理。 |
| 状态识别 | 未知状态不视为断开；有线仅启用不视为连接；只匹配指定 WiFi 接口和目标配置；netsh 调用设置超时。 |
| 进程管理 | 按完整可执行文件路径匹配，先发送窗口关闭请求；等待超时后，仅对仍然匹配且 PID 未被重用的进程强制终止。无法读取路径的进程跳过。 |
| 打包 | 四个入口复用同一 PowerShell 实现，每次使用独立输出和工作目录，不结束运行进程、不删除旧包；分发包仅含配置模板。 |
| 敏感文件 | 忽略 network_config 的配置副本和备份，明确保留 network_config.ini.example；已有本地文件保留。 |
| 保持在线 | 显式声明无符号 DWORD 并使用 32 位模减；每代线程独立停止事件，旧线程清理后执行最后一次开启请求。 |
| 自启动 | 不限制任务持续运行时间；注册使用覆盖更新而非先删除旧任务；错误终止执行，写入后重新查询验证；独立启停脚本同步修正。 |
| 代理重连 | 单次检查期间的重连请求升级为持续在家守护；收尾期间接收的请求在资源释放后继续执行；停止过程不承诺接受新请求。 |
| 配置定位 | 源码运行读取项目根目录，打包运行读取 EXE 所在目录，显式传入的配置路径优先。 |
| 多实例及退出 | 同一 Windows 用户会话仅允许一份新版运行；切换或回滚网络期间，退出操作会提示稍候。 |

保留原有菜单、配置键、网络操作的 `(success, reason)` 返回格式，以及代理守护的备份、手动开启和未知状态保护。
