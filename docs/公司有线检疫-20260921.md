# 公司有线检疫（v1.2.3）

> 历史说明，已由 v1.2.4 的简单脚本代理按钮替代。新版启动时脚本代理开、手动代理关，用户自行开启守护；已移除本文的检疫确认流程。

日常只需两个操作，均在 WorkPal 托盘的“代理守护”菜单中：

1. **开始公司检疫**：先启用公司脚本代理，再打开 iNetSec。已运行时不重启，请查看它的托盘图标并按原来的方式完成检疫。
2. iNetSec 当前图标为**绿色通过状态**后，点 **检疫已通过**：确认有线连接和公司代理可达后切换到手动代理，继续原来的低频守护。红点时不确认。

从 WorkPal 的网络切换功能切到有线时，会自动执行第一步。平时已经插着网线，直接点“开始公司检疫”即可，不切换网卡。

检疫阶段，定时守护和“立即检查并修复一次”都保持脚本代理。通过确认以后，守护才会修复被改回脚本的设置。检查间隔沿用原来保存的 1/2/5 分钟。

普通解锁且连接未变化时不用再次确认。发现有线断开、地址改变或网卡状态无法确认后，需要检查当前图标再确认。暂停或退出后再次启动也需要重新确认。若图标变红或网络要求重新检疫，直接再点“开始公司检疫”。

本版本不自动识别绿色/红色图标。用户提供的截图确认了图标含义；所读本地日志仅包含未核实含义的内部返回值，不能用于自动认定通过。进程存在、窗口消失、TCP 端口可达也不能代表检疫通过。

只设置当前用户 LAN 代理及启动已有客户端。不修改 iNetSec 或 FortiClient 的配置、服务、凭据；不会杀死或强制重启 iNetSec。原代理备份和旧程序保留。测试使用替身，不操作真实网卡、代理或 VPN；实际检疫通过仍以用户本机图标为准。
